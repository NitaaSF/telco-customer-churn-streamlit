# Telco Customer Churn Analysis & Interactive Dashboard

Proyek analisis data *end-to-end* untuk mengidentifikasi faktor-faktor pendorong (*drivers*) kepergian pelanggan (*churn*) pada industri telekomunikasi menggunakan dataset IBM Telco. Proyek ini mencakup proses *data cleaning*, *feature engineering*, visualisasi BI dengan **Tableau**, serta aplikasi web analitik interaktif berbasis **Python Streamlit & Plotly**.
